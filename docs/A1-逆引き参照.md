## 3. 索引C: 症状からの逆引き

参照先の番号は[落とし穴カタログ](A3-落とし穴.md)の項番です。

### 値・変数がおかしい

| 症状 | まず疑うところ | 参照先 |
|---|---|---|
| ループ内の出力が初期値のまま変わらない | `%VAR%` を `!VAR!` にする（遅延展開） | [#1](A3-落とし穴.md#1-ループ内で変数が更新されない) |
| 比較が成立しない | `set VAR = value` の空白 / 未定義変数 | [#2](A3-落とし穴.md#2-比較が成立しない--値の末尾に空白が入る) |
| 値の末尾に空白が入っている | `set "名前=値"` の形にする | [#2](A3-落とし穴.md#2-比較が成立しない--値の末尾に空白が入る) |
| `%VAR%` がそのまま表示される | 変数が未定義。置換できず元の文字列が残っている | [01.2](01-実行モデル.md#2-実行モデル--1行が実行されるまで) |
| `&` を含む値を `echo` したら壊れた | 展開結果が読み直されている。`!VAR!` で読む | [02.4](02-制御構文.md#4-遅延展開--この回の山場) |
| 実行後、環境変数が書き換わっている | `setlocal` がない | [#13](A3-落とし穴.md#13-実行後環境変数が書き換わっている) |
| 拡張子なしのファイルで変な値になる | 空の変数に置換記法を使っている | [02.8](02-制御構文.md#8-デモ--ループと振り分け) |

### エラーメッセージが出る

| メッセージ | まず疑うところ | 参照先 |
|---|---|---|
| `この時点では予期されていません。` | 括弧・引用符・エスケープ（`&` `\|` `%`） | [#10](A3-落とし穴.md#10--を含む文字列が消える) |
| `コマンドの構文が誤っています。` | 引用符 / 空白を含むパス / `::` を括弧内に書いた | [#5](A3-落とし穴.md#5-パスに空白が含まれると失敗する) [#9](A3-落とし穴.md#9--コメントを入れたらループが構文エラーになった) |
| `指定されたパスが見つかりません。` | カレントディレクトリ / `%~dp0` の連結 | [#4](A3-落とし穴.md#4-ダブルクリックでは動くのに別の場所から呼ぶと失敗する) |
| `UNC パスはサポートされません。` | `cd` を `pushd` にする | [#14](A3-落とし穴.md#14-共有フォルダunc-パスでカレント移動が失敗する) |
| `パス演算子の次の使用方法は無効です` | `%~` の直後が修飾子になっていない（コメント行も対象） | [01.2](01-実行モデル.md#2-実行モデル--1行が実行されるまで) |
| ラベルが見つからない旨のメッセージ | `goto` 先のスペル / `::` の位置 | [#9](A3-落とし穴.md#9--コメントを入れたらループが構文エラーになった) |
| `'…' は、内部コマンドまたは外部コマンド…` | 値の中の `&` が区切りとして解釈された | [02.4](02-制御構文.md#4-遅延展開--この回の山場) |

> <strong>症状から引けなかったときは `@echo off` を外してください。</strong>実行される1行1行が**展開後の姿**で表示されるため、どの行でどう化けたかが直接見えます。バッチにはデバッガがないので、これが最も確実な調査手段です。
