# DOSコマンド勉強会 資料

Windows のバッチファイル（`.bat` / `.cmd`）を自分で書けるようになるための全3回シリーズ

> 📅 作成: 2026-08-24 / 更新: 2026-10-10

[^^](../)

対象は **JavaScript の基礎文法・開発経験がある人**、または **Java か C# を知っている人**です。勉強会では 01 から 03 を順に読み（各回60分）、A1 から A3 は実際に書くときに引きます。
